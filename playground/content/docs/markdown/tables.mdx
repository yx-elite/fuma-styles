Tables compare several things on several points. They must stay readable on a phone, which usually means scrolling sideways inside the table, not the page.

## Simple table

| Term | Meaning |
| --- | --- |
| Hit | Found in the cache |
| Miss | Fetched from the origin |
| Eviction | Removed to make space |

## Long text in cells

| Strategy | How it works | When to use it |
| --- | --- | --- |
| Cache-aside | The application checks the cache first. On a miss it reads the origin, then writes the result into the cache for next time. | Read-heavy data that can be a little stale, where only requested items should take up cache space. |
| Write-through | Every write goes to the cache and the origin together, so the cache is always current. | Data that is read soon after it is written and must not be stale. |
