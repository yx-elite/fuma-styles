Everything that differs between notes sites lives in `site.config.ts` at the root of your app. The theme reads it for the header, sidebar, landing page and accent colour.

```ts title="site.config.ts"
import { defineSiteConfig } from '@yx-elite/notestack';

export default defineSiteConfig({
  name: 'AWS SAA-C03 Notes',
  author: 'your-name',
  tag: 'SAA-C03',
  description: 'Study notes for the AWS Solutions Architect Associate exam.',
  repo: 'your-name/aws-saa-notes',
  accent: { light: '#d97706', dark: '#fcd34d' },
  links: [
    { text: 'Home', url: '/docs', icon: 'House' },
    { text: 'Glossary', url: '/docs/glossary', icon: 'BookA' },
  ],
});
```

## Accent colours

Pick a deeper shade for light mode and a lighter one for dark mode, so text in the accent colour stays readable on both backgrounds. The theme makes a second tone from it for gradients. Try colours live with the palette button in the corner of this site, then copy the pair you like. More in [Theme and accent](/docs/theme).

## Quick links

Quick links stay fixed under the sidebar banner while the page list scrolls. Use them for the two or three pages readers open most, such as a glossary or an exam overview. Icons come from [Lucide](https://lucide.dev/icons).

## Sidebar order and titles

The order of pages and the section titles in the sidebar come from `meta.json` files next to your notes, and each page's title, description and icon from its frontmatter. Both are standard Fumadocs: see [Organizing pages](https://fumadocs.dev/docs/next/page-conventions).
