## Tabs and steps

Tabs show alternatives side by side. Steps guide a reader through a process in order.

### Tabs

<Tabs items={['Console', 'CLI', 'Terraform']}>
  <Tab value="Console">
    Open the **S3** page, choose **Create bucket**, enter a name and keep the default settings.
  </Tab>
  <Tab value="CLI">
    ```bash
    aws s3 mb s3://example-bucket --region ap-southeast-1
    ```
  </Tab>
  <Tab value="Terraform">
    ```hcl
    resource "aws_s3_bucket" "example" {
      bucket = "example-bucket"
    }
    ```
  </Tab>
</Tabs>

### Tabs with longer content

<Tabs items={['Strengths', 'Weaknesses']}>
  <Tab value="Strengths">
    - Fast reads for repeated requests
    - Less load on the origin
    - Lower cost per request

    A cache pays off most when the same data is read many times.
  </Tab>
  <Tab value="Weaknesses">
    - Stale data until the copy expires
    - Extra moving parts to monitor
    - Cold start after a restart
  </Tab>
</Tabs>

### Steps

<Steps>
  <Step>
    ### Create the bucket

    Pick a name that is unique across all accounts, and the Region closest to users.
  </Step>
  <Step>
    ### Upload the site

    Upload the static files, keeping the folder structure:

    ```bash
    aws s3 sync out/ s3://example-bucket --delete
    ```
  </Step>
  <Step>
    ### Point the domain at it

    Add a DNS record for the domain. The change can take a few minutes to reach every resolver.
  </Step>
  <Step>
    ### Check it works

    Open the site in a private window, so no old copy from the browser cache is shown.
  </Step>
</Steps>

## Accordions and files

Accordions hide detail until it is needed, which suits practice questions. File trees show how a project is laid out.

### Accordions

Opening one panel closes the one that was open.

<Accordions>
  <Accordion title="What is a cache hit?">
    The requested data was found in the cache, so the origin was not asked.
  </Accordion>
  <Accordion title="Why can a cache return old data?">
    Because the cached copy stays valid until its TTL runs out, even if the original has changed.
  </Accordion>
  <Accordion title="How can stale data be avoided?">
    - Use a shorter TTL
    - Clear the cached copy when the original changes
    - Version file names, so new content gets a new URL
  </Accordion>
</Accordions>

### Accordions open together

With `multiple`, several panels stay open at once. Open both to check.

<Accordions multiple>
  <Accordion title="Question 1">This one stays open when you open Question 2.</Accordion>
  <Accordion title="Question 2">
    An answer with code:

    ```bash
    curl -I https://example.com
    ```
  </Accordion>
</Accordions>
