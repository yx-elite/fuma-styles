  - `no-store`: never keep a copy

## Accordions

### One open at a time

Opening one panel closes the other. The second has an `id`, so it gets a button that copies a link to it.

<Accordions>
  <Accordion title="What is a cache hit?">
    The requested data was found in the cache, so the origin was not asked.
  </Accordion>
  <Accordion title="How can stale data be avoided?" id="avoid-stale-data">
    - Use a shorter TTL
    - Clear the cached copy when the original changes
  </Accordion>
</Accordions>

### Several open

With `multiple`, panels stay open together. Open both to check.

<Accordions multiple>
  <Accordion title="Question 1">This one stays open when you open Question 2.</Accordion>
  <Accordion title="Question 2">
    An answer with code:

    ```bash
    curl -I https://example.com
    ```
  </Accordion>
</Accordions>
