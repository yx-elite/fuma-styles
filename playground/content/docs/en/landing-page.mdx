The landing page is built from your notes and `site.config.ts`, so a new site has a complete one with nothing to write. As notes are added, it updates itself.

## What it shows

| Part | Comes from |
| --- | --- |
| Badge, title and description | `tag`, `name` and `description` in the config |
| Page count, section count, last update | Your notes, and their latest git commit |
| Docs preview | A live miniature of the docs, drawn from the sidebar, in the current theme and accent |
| Built with | Notestack, then the libraries every site runs on |
| What's inside | A mosaic with one card per sidebar section, each showing the section a different way |
| Get started | `start` in the config |
| Search | Opens the site search |
| Footer | `name`, `description`, `repo` and `author`. Also the sections again, your `links`, and a *Built with Notestack* link |

Moving from the landing page into the docs, and back, is animated. See [Page transitions](/docs/features#page-transitions).

## Get started

By default, the "Get started" section shows how to run the notes on your own machine: clone the repository, install, and run. Set `start` to show your own steps, or `false` to hide it:

```ts title="site.config.ts"
start: {
  title: 'Run the notes on your machine',
  text: 'Three commands, and you can read the notes offline.',
  steps: [
    { title: 'Clone', text: 'Get a copy from GitHub.', command: 'git clone https://github.com/you/notes.git' },
    { title: 'Install', text: 'Install the packages.', command: 'cd notes && npm install' },
    { title: 'Run', text: 'Open localhost:3000.', command: 'npm run dev' },
  ],
},
```

Each step is shown in the list, and its command is typed into the terminal beside it. After the last command, the terminal shows *Ready on http://localhost:3000*. Set `done` in `start` to change that line.

## Sections

The "What's inside" cards, and the *Notes* column of the footer, follow your [sidebar](/docs/pages#the-sidebar) (`content/docs/meta.json`). Rename or reorder it there and the landing page follows:

- Each section heading (`---Title---`) starts a card, with the pages under it.
- A folder right after a heading belongs to that card. Any other folder gets a card of its own, named after the folder.
- Pages before the first heading go on a card called *Start here*.
- *Start reading* opens `/docs`, which is `content/docs/index.mdx`. The docs preview opens the first page of the first card.

The cards form a mosaic of different sizes. Each shows its section a different way, using only what every section has: its name, its page count, its page titles and the pages' `icon:` frontmatter.

| Card | Where | What it shows |
| --- | --- | --- |
| Feature | The first section, tall on the left | The name in large type, the first page's description, every page as a chip, and a link to the first page |
| Cluster | Top right | The pages' icons, overlapping |
| Stack | Below it | The first four pages, one under another |
| Count | Beside the stack | The page count, in large type |
| Strip | Every section after the fourth, two to a row | The name and the pages as chips, on one line |

A page without an `icon:` shows its number in place of an icon. With fewer than four sections, the mosaic uses fewer, larger cards. On a phone, the cards stack in sidebar order. Every card links to its section's first page.

## Your own landing page

To replace it, write your own `app/(home)/page.tsx`. The header and the page transitions keep working. To change only the wording, such as *Start reading* or *What's inside*, set `text` in `site.config.ts`. [Languages](/docs/languages#built-in-text) explains how.
