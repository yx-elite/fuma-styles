Everything that differs between notes sites lives in `site.config.ts` at the root of your app. The theme reads it for the header, sidebar, landing page and accent colour.

```ts title="site.config.ts"
import { defineSiteConfig } from '@yx-elite/notestack';

export default defineSiteConfig({
  name: 'Networking Notes',
  author: 'your-name',
  tag: 'NET-101',
  description: 'Study notes for an introductory networking course.',
  repo: 'your-name/networking-notes',
  url: 'https://notes.example.com',
  accent: { light: '#d97706', dark: '#fcd34d' },
  links: [
    { text: 'Home', url: '/docs', icon: 'House' },
    { text: 'Glossary', url: '/docs/glossary', icon: 'BookA' },
  ],
});
```

## Accent colours

[Theme and accent](/docs/theme#accent-colour) explains how to pick the light and dark pair and try colours live.

## Language

Set `language` for a site in one language other than English, or `languages` and `translations` for several. [Languages](/docs/languages) explains both.

## Site address

Set `url` once the site has an address. A link to one of your notes, pasted into a chat app or a social post, then shows a preview with the note's title. Without it, everything else works the same. See [Share images](/docs/features#share-images).

## Quick links

Quick links stay fixed under the sidebar banner while the page list scrolls. Use them for the two or three pages readers open most, such as a glossary or a course overview. Icons come from [Lucide](https://lucide.dev/icons).

## Set elsewhere

A few things aren't in `site.config.ts`:

| To change | See |
| --- | --- |
| The sidebar order, section titles, and each page's title and icon | [Pages and sidebar](/docs/pages#the-sidebar) |
| The logo and the browser-tab icon | [Theme and accent](/docs/theme#logo-and-favicon) |
| Glow, grid, widths and fonts | [Theme and accent](/docs/theme#css-variables) |
| Your own components, a site in a subfolder, Next.js options | [Advanced](/docs/advanced) |
