Everything that differs between notes sites lives in `site.config.ts` at the root of your app. The theme reads it for the header, sidebar, landing page and accent colour.

```ts title="site.config.ts"
import { defineSiteConfig } from '@yx-elite/notestack';

export default defineSiteConfig({
  name: 'AWS SAA-C03 Notes',
  author: 'your-name',
  tag: 'SAA-C03',
  description: 'Study notes for the AWS Solutions Architect Associate exam.',
  repo: 'your-name/aws-saa-notes',
  url: 'https://saa.example.com',
  accent: { light: '#d97706', dark: '#fcd34d' },
  links: [
    { text: 'Home', url: '/docs', icon: 'House' },
    { text: 'Glossary', url: '/docs/glossary', icon: 'BookA' },
  ],
});
```

## Accent colours

Pick a deeper shade for light mode and a lighter one for dark mode, so text in the accent colour stays readable on both backgrounds. The theme makes a second tone from it for gradients. Try colours live with the palette button in the corner of this site, then copy the pair you like. More in [Theme and accent](/docs/theme).

## Language

Set `language` to the language your notes are written in. The page's `lang`, dates and every piece of text the theme shows follow it, including Fumadocs' search box, *On this page* and page buttons.

```ts title="site.config.ts"
export default defineSiteConfig({
  // …
  language: 'zh-CN',
});
```

The theme's own text ships in English and Simplified Chinese. Fumadocs' text also comes in Traditional Chinese and Japanese. For any other language, or to change a single phrase, fill in `text`. Anything you leave out stays in English:

```ts title="site.config.ts"
export default defineSiteConfig({
  // …
  language: 'ms',
  text: {
    startReading: 'Mula membaca',
    pageCount: { other: '{n} halaman' },
  },
});
```

`{n}`, `{date}` and other words in braces are filled in by the theme. A text that depends on a count takes one form per plural category of your language. English uses `one` and `other`, Chinese only `other`.

## Several languages

To publish the same notes in more than one language, list them in `languages` (the first is the default) and put each language's text in `translations`. URLs then start with the language (`/en/docs/…`), notes live in one folder per language, and a language switch appears in the header. It needs a few more files in `app/`: the [Languages](/docs/languages) guide walks through it.

## Site address

Set `url` once the site has an address. A link to one of your notes, pasted into a chat app or a social post, then shows a preview with the note's title. Without it, everything else works the same.

## Quick links

Quick links stay fixed under the sidebar banner while the page list scrolls. Use them for the two or three pages readers open most, such as a glossary or an exam overview. Icons come from [Lucide](https://lucide.dev/icons).

## Sidebar order and titles

The order of pages and the section titles in the sidebar come from `meta.json` files next to your notes, and each page's title, description and icon from its frontmatter. Both are standard Fumadocs: see [Organizing pages](https://fumadocs.dev/docs/next/page-conventions).
