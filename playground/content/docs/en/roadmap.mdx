Notestack is young and changing quickly. This page lists what's done and what's planned. To suggest something or help build it, see [Contributing](/docs/contributing).

## Status

| What | Status |
| --- | --- |
| First release on npm (`0.1.0`), and `npm create notestack` | Done |
| Tests, type check and build on every push to `main` and every pull request | Done |
| This docs site, deployed as a public website | Next |
| A ready-made deploy workflow for notes repos | Planned |
| **Obsidian**: publish an Obsidian vault as it is, including wikilinks, embeds and `> [!note]` callouts | Not planned |
| More note components: checklists that remember ticks, worked calculations, terms that show their definition on hover | Ideas |
| More built-in languages for the theme's text | Open to contributions |

<Callout type="info" title="About Obsidian">
Publishing an Obsidian vault as it is was tried early on and dropped, because the tools for it needed too many workarounds to keep the promise. It's not planned. Notes are Markdown files in `content/docs/`, which Obsidian can still open and edit. To publish a vault as it is, [Quartz](https://quartz.jzhao.xyz) is built for that.
</Callout>
