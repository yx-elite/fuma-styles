Notestack is young and changing quickly. This page lists what's planned. To suggest something or help build it, see [Contributing](/docs/contributing).

## Coming next

| What | Status |
| --- | --- |
| First release on npm, and `npm create notestack` | In progress |
| Builds checked on every push, and a ready-made deploy workflow for notes repos | Planned |
| **Obsidian**: write notes in an Obsidian vault and publish them with the theme, including wikilinks, embeds and `> [!note]` callouts | Coming later |
| More note components: checklists that remember ticks, worked calculations, terms that show their definition on hover | Ideas |
| More built-in languages for the theme's text | Open to contributions |

<Callout type="info" title="About Obsidian">
Publishing an Obsidian vault as it is was tried early on and set aside, because the tools for it needed too many workarounds to keep the promise. It will come back once it can work properly. Until then, notes are Markdown files in `content/docs/`, which Obsidian can also open and edit.
</Callout>
