**Notestack** (`@yx-elite/notestack`) is a theme for [Fumadocs](https://fumadocs.dev). It turns a plain Fumadocs app into a notes site with a designed look: header, sidebar, landing page, page transitions and styled content. Your notes stay plain Markdown or MDX.

<Callout type="warn" title="In development">
The package is not published yet. These pages describe the first release, and this site is its live demo.
</Callout>

## Why

Writing notes is the point; setting up a site for them should not be. Notestack keeps the setup to one install and one config file:

- **One config file.** Name, links, accent colour and landing page all come from `site.config.ts`.
- **Updates through npm.** Design and fixes ship in the package, so every notes site gets them with `npm update`.
- **Static and cheap to host.** Every site is a static export: plain files on S3 or any static host, no server.
- **Built on Fumadocs.** Search, the sidebar and MDX come from Fumadocs itself; the theme only adds the design and a few notes features.

## Features

| Feature | What you get |
| --- | --- |
| Design | Black theme, one accent colour with a matching second tone, background grid and glow, Geist and JetBrains Mono fonts |
| Layout | Full-width notes layout, header on top, sidebar banner and quick links, pinned current page, *On this page* list |
| Landing page | Built from your content: a live preview of the docs, section cards, a "Get started" section |
| Motion | Smooth page transitions between the landing page and the docs, tuned for Safari |
| Notes features | Glossary page, last-updated dates from git, static search, share images, plain-text copies for AI assistants (llms.txt) |
| Content | Markdown and MDX pages, with components such as tabs, steps and cards |
| Languages | One language per site, or several with a language switch |
| Devices | Phones, tablets (sidebar as a side panel) and desktops, in light and dark mode |
| Hosting | A static export: Cloudflare, GitHub Pages, Netlify, Vercel, S3 or any file host |
