A notes site is a static export: plain HTML, CSS and JavaScript files with no server. It can be hosted anywhere that serves files, for very little.

## Build

```bash
npm run build
```

The site is written to `out/`. Search works without a server too: its index is built at the same time and searched in the browser.

## Last updated dates

Each page's *Last updated* date is its latest git commit. Build from a full clone, not a shallow one, or every page shows the same date. On GitHub Actions:

```yaml title=".github/workflows/deploy.yml"
- uses: actions/checkout@v4
  with:
    fetch-depth: 0
```

## Hosting on S3 with Cloudflare

The lowest-cost setup, and the one this theme is tested with:

<Steps>
<Step>

### Create a bucket

Create an S3 bucket named after the site's domain, such as `notes.example.com`, and turn on static website hosting with `index.html` as the index document.

</Step>
<Step>

### Upload the build

```bash
aws s3 sync out/ s3://notes.example.com --delete
```

</Step>
<Step>

### Point Cloudflare at it

Add a proxied `CNAME` record for `notes` that points to the bucket's website endpoint. Cloudflare serves the site over HTTPS and caches it worldwide.

</Step>
</Steps>

Every page is a folder with an `index.html` (`/docs/vpc/` is `docs/vpc/index.html`), which S3 serves as is.

## Other hosts

The `out/` folder works on any static host, such as GitHub Pages, Cloudflare Pages or Netlify: upload it, or point the host at your repository with `npm run build` as the build command and `out` as the output folder.
