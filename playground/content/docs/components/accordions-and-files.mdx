Accordions hide detail until it is needed, which suits practice questions. File trees show how a project is laid out.

## Accordions

<Accordions type="single">
  <Accordion title="What is a cache hit?">
    The requested data was found in the cache, so the origin was not asked.
  </Accordion>
  <Accordion title="Why can a cache return old data?">
    Because the cached copy stays valid until its TTL runs out, even if the original has changed.
  </Accordion>
  <Accordion title="How can stale data be avoided?">
    - Use a shorter TTL
    - Clear the cached copy when the original changes
    - Version file names, so new content gets a new URL
  </Accordion>
</Accordions>
