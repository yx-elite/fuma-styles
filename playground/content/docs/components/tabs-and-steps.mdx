## Tabs

<Tabs items={['Console', 'CLI', 'Terraform']}>
  <Tab value="Console">
    Open the **S3** page, choose **Create bucket**, enter a name and keep the default settings.
  </Tab>
  <Tab value="CLI">
    ```bash
    aws s3 mb s3://example-bucket --region ap-southeast-1
    ```
  </Tab>
  <Tab value="Terraform">
    ```hcl
    resource "aws_s3_bucket" "example" {
      bucket = "example-bucket"
    }
    ```
  </Tab>
</Tabs>

## Tabs with longer content

<Tabs items={['Strengths', 'Weaknesses']}>
  <Tab value="Strengths">
    - Fast reads for repeated requests
    - Less load on the origin
    - Lower cost per request

    A cache pays off most when the same data is read many times.
  </Tab>
  <Tab value="Weaknesses">
    - Stale data until the copy expires
    - Extra moving parts to monitor
    - Cold start after a restart
  </Tab>
</Tabs>

## Steps

<Steps>
  <Step>
    ### Create the bucket

    Pick a name that is unique across all accounts, and the Region closest to users.
  </Step>
  <Step>
    ### Upload the site

    Upload the static files, keeping the folder structure:

    ```bash
    aws s3 sync out/ s3://example-bucket --delete
    ```
  </Step>
  <Step>
    ### Point the domain at it

    Add a DNS record for the domain. The change can take a few minutes to reach every resolver.
  </Step>
  <Step>
    ### Check it works

    Open the site in a private window, so no old copy from the browser cache is shown.
  </Step>
</Steps>
