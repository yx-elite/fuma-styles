**Notestack**（`@yx-elite/notestack`）是 [Fumadocs](https://fumadocs.dev) 的一个主题。它把一个普通的 Fumadocs 应用变成一个有设计感的笔记网站：页头、侧边栏、首页、页面过渡动画和排版好的内容。你的笔记仍然是普通的 Markdown 或 MDX。

## 为什么

写笔记才是重点，搭网站不该是。Notestack 把搭建工作减少到一次安装和一个配置文件：

- **一个配置文件。** 名称、链接、强调色和首页都来自 `site.config.ts`。
- **通过 npm 更新。** 设计和修复都随包发布，每个笔记网站运行 `npm update` 就能获得。
- **静态，托管便宜。** 每个网站都是静态导出：放在 S3 或任何静态托管上的普通文件，不需要服务器。
- **基于 Fumadocs。** 搜索、侧边栏和 MDX 都来自 Fumadocs 本身；主题只增加设计和一些笔记功能。

## 功能

| 功能 | 你会得到 |
| --- | --- |
| 设计 | 黑色主题，一个强调色及与之搭配的第二色调，背景网格和光晕，Geist 与 JetBrains Mono 字体 |
| 布局 | 全宽笔记布局，顶部页头，侧边栏横幅和快速链接，固定显示当前页面，*本页目录* 列表 |
| 首页 | 由你的内容生成：文档的实时预览、章节卡片、"快速开始"部分 |
| 动效 | 首页与文档之间流畅的页面过渡，针对 Safari 调优 |
| 笔记功能 | 术语表页面、静态搜索、来自 git 的最后更新日期、分享图片，以及供 AI 助手使用的纯文本副本（llms.txt）。详见[内置功能](/docs/features)。 |
| 内容 | Markdown 和 MDX 页面，可使用标签页、步骤和卡片等组件 |
| 语言 | 一个网站一种语言，或多种语言并带有语言切换 |
| 设备 | 手机、平板（侧边栏作为侧滑面板）和电脑，支持浅色和深色模式 |
| 托管 | 静态导出：Cloudflare、GitHub Pages、Netlify、Vercel、S3 或任何文件托管 |
