## 环境要求

- [Node.js](https://nodejs.org) 22 或更高版本。用 `node --version` 查看。
- npm，随 Node.js 一起安装。
- [Git](https://git-scm.com)，用于*最后更新*日期和发布笔记。
- 一个代码编辑器，例如 [VS Code](https://code.visualstudio.com)。

Notestack 用 Next.js 和 Fumadocs MDX 构建自己的网站，并以静态导出发布。它不能接入用其他方式搭建的 Fumadocs 应用，例如使用服务器、其他框架或其他内容来源的应用。

## 创建网站

<Steps>
<Step>

### 创建网站

```bash
npm create notestack@latest my-notes
```

这会新建一个 `my-notes` 文件夹，里面是一个已经配置好主题的笔记网站，并安装好所需的一切。文件夹名称可以随意取。

</Step>
<Step>

### 启动

```bash
cd my-notes
npm run dev
```

打开 [localhost:3000](http://localhost:3000)。保存文件后网站会自动更新。按 <kbd>Ctrl</kbd> + <kbd>C</kbd> 停止。

</Step>
<Step>

### 改成你自己的

打开 `site.config.ts`，填写网站的 `name`、`description` 和 `repo`。所有选项见[配置](/docs/configuration)。

网站自带一份简短的示例，每个功能展示一次：一个欢迎页、一个 `example` 文件夹和一个术语表。准备好写自己的笔记时，按下面的步骤删掉它：

1. 删除 `content/docs/example/`，再从 `content/docs/meta.json` 中删掉 `"...example"`。
2. 把 `content/docs/index.mdx` 的内容换成你自己的简介。保留这个文件，因为首页的*开始阅读*按钮会打开它。
3. 在 `content/glossary.json` 中填写你自己的术语，或者[删掉术语表](/docs/glossary#remove-the-glossary)。

然后把笔记放进 `content/docs/`。[页面与侧边栏](/docs/pages)讲解了写法。

</Step>
<Step>

### 保存到 GitHub

```bash
git init
git add .
git commit -m "My notes"
```

然后在 GitHub 上新建一个空仓库，按照它的提示推送。发布网站见[部署](/docs/deployment)。

</Step>
</Steps>

## 常用命令

在网站文件夹中运行：

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 写作时在 localhost:3000 启动网站 |
| `npm run build` | 把整个网站构建成 `out/` 里的普通文件 |
| `npm start` | 在本机查看构建好的 `out/`，和发布后完全一样 |
| `npm run types:check` | 检查代码错误（更新之后很有用） |

## 网站里有什么

只有 Next.js 和 Fumadocs 要求必须存在的文件。每个文件只有几行，调用主题，所以以后的新版本通过 `npm update` 就能到达你的网站（见[更新与版本](/docs/updates)）：

<Files>
  <File name="site.config.ts" />
  <Folder name="content" defaultOpen>
    <Folder name="docs" defaultOpen>
      <File name="meta.json" />
      <File name="index.mdx" />
      <Folder name="example" />
      <File name="glossary.mdx" />
    </Folder>
    <File name="glossary.json" />
  </Folder>
  <Folder name="app" defaultOpen>
    <File name="layout.tsx" />
    <File name="global.css" />
    <File name="icon.svg" />
    <Folder name="(home)">
      <File name="layout.tsx" />
      <File name="page.tsx" />
    </Folder>
    <Folder name="docs">
      <File name="layout.tsx" />
      <File name="[[...slug]]/page.tsx" />
    </Folder>
    <Folder name="api/search">
      <File name="route.ts" />
    </Folder>
    <Folder name="og/docs/[...slug]">
      <File name="route.tsx" />
    </Folder>
    <Folder name="llms.txt">
      <File name="route.ts" />
    </Folder>
    <Folder name="llms-full.txt">
      <File name="route.ts" />
    </Folder>
    <Folder name="llms.mdx/[...path]">
      <File name="route.ts" />
    </Folder>
  </Folder>
  <Folder name="lib">
    <File name="source.ts" />
  </Folder>
  <File name="next.config.mjs" />
  <File name="postcss.config.mjs" />
  <File name="tsconfig.json" />
  <File name="package.json" />
  <File name="README.md" />
</Files>

| 文件 | 作用 | 需要编辑吗？ |
| --- | --- | --- |
| `site.config.ts` | 网站的名称、链接、颜色和语言 | **需要** |
| `content/docs/` | 你的笔记，以及决定侧边栏顺序的 `meta.json`。`index.mdx` 是第一页，`example/` 是示例 | **需要** |
| `content/glossary.json` | 术语表的术语 | **需要** |
| `app/icon.svg` | 浏览器标签页图标 | 想换就换 |
| `app/layout.tsx` | 字体，然后是 `NotesRoot`：强调色、搜索和页面过渡 | 不需要 |
| `app/global.css` | 加载 Tailwind CSS 和主题 | 不需要 |
| `app/(home)/` | 首页，由你的笔记生成 | 不需要 |
| `app/docs/` | 笔记布局和每篇笔记的页面 | 不需要 |
| `app/api/search/` | 搜索索引，构建时生成，在浏览器中搜索 | 不需要 |
| `app/og/docs/` | 分享图片：链接在聊天应用中显示的预览图 | 不需要 |
| `app/llms*/` | 给 AI 助手的纯文本笔记，以及*复制 Markdown* | 不需要 |
| `lib/source.ts` | 从 `content/docs/` 读取笔记 | 不需要 |
| `next.config.mjs` | 静态导出设置，无需服务器即可托管 | 不需要 |
| `postcss.config.mjs`、`tsconfig.json` | Tailwind CSS 和 TypeScript 设置 | 不需要 |
