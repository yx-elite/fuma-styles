<Callout type="warn" title="开发中">
`@yx-elite/notestack` 和 `create-notestack` 还没有发布。下面是第一个正式版本中的安装方式。在那之前，[仓库](https://github.com/yx-elite/notestack)里的 `starter/` 文件夹就是同一个网站。
</Callout>

## 环境要求

- [Node.js](https://nodejs.org) 22 或更高版本。用 `node --version` 查看。
- npm，随 Node.js 一起安装。
- [Git](https://git-scm.com)，用于*最后更新*日期和发布笔记。
- 一个代码编辑器，例如 [VS Code](https://code.visualstudio.com)。

## 创建网站

<Steps>
<Step>

### 创建网站

```bash
npm create notestack@latest my-notes
```

这会新建一个 `my-notes` 文件夹，里面是一个已经配置好主题的笔记网站，并安装好所需的一切。文件夹名称可以随意取。

</Step>
<Step>

### 启动

```bash
cd my-notes
npm run dev
```

打开 [localhost:3000](http://localhost:3000)。保存文件后网站会自动更新。按 <kbd>Ctrl</kbd> + <kbd>C</kbd> 停止。

</Step>
<Step>

### 改成你自己的

打开 `site.config.ts`，填写网站的 `name`、`description` 和 `repo`。所有选项见[配置](/docs/configuration)。

</Step>
<Step>

### 写作

把笔记放进 `content/docs/`。网站自带一份简短的示例（欢迎页、一个示例主题和术语表），每个功能展示一次；准备好后删掉即可。见[写笔记](/docs/writing-notes)。

</Step>
<Step>

### 保存到 GitHub

```bash
git init
git add .
git commit -m "My notes"
```

然后在 GitHub 上新建一个空仓库，按照它的提示推送。发布网站见[部署](/docs/deployment)。

</Step>
</Steps>

## 常用命令

在网站文件夹中运行：

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 写作时在 localhost:3000 启动网站 |
| `npm run build` | 把整个网站构建成 `out/` 里的普通文件 |
| `npm start` | 在本机查看构建好的 `out/`，和发布后完全一样 |
| `npm run types:check` | 检查代码错误（更新之后很有用） |

## 网站里有什么

只有 Next.js 和 Fumadocs 要求必须存在的文件。每个文件只有几行，调用主题，所以以后的新版本通过 `npm update` 就能到达你的网站：

| 文件 | 作用 | 需要编辑吗？ |
| --- | --- | --- |
| `site.config.ts` | 网站的名称、链接、颜色和语言 | **需要** |
| `content/docs/` | 你的笔记，以及决定侧边栏顺序的 `meta.json`。`index.mdx` 是第一页，`example/` 是示例 | **需要** |
| `content/glossary.json` | 术语表的术语 | **需要** |
| `app/icon.svg` | 浏览器标签页图标 | 想换就换 |
| `app/layout.tsx` | 字体，然后是 `NotesRoot`：强调色、搜索和页面过渡 | 不需要 |
| `app/global.css` | 加载 Tailwind CSS 和主题 | 不需要 |
| `app/(home)/` | 首页，由你的笔记生成 | 不需要 |
| `app/docs/` | 笔记布局和每篇笔记的页面 | 不需要 |
| `app/api/search/` | 搜索索引，构建时生成，在浏览器中搜索 | 不需要 |
| `app/og/docs/` | 分享图片：链接在聊天应用中显示的预览图 | 不需要 |
| `app/llms*/` | 给 AI 助手的纯文本笔记，以及*复制 Markdown* | 不需要 |
| `lib/source.ts` | 从 `content/docs/` 读取笔记 | 不需要 |
| `next.config.mjs` | 静态导出设置，无需服务器即可托管 | 不需要 |
| `postcss.config.mjs`、`tsconfig.json` | Tailwind CSS 和 TypeScript 设置 | 不需要 |

## 加进已有的 Fumadocs 应用

如果你已经有一个 Fumadocs 应用（用 `npm create fumadocs-app` 创建，使用 Next.js 和 Fumadocs MDX），可以手动换成这个主题。以起始模板为准：下面每个文件都是它的副本。

<Steps>
<Step>

### 安装主题

```bash
npm install @yx-elite/notestack
```

你的应用需要 `fumadocs-core` 和 `fumadocs-ui` 16、`fumadocs-mdx`、`next` 16、`react` 19 和 Tailwind CSS 4。主题使用你应用里的这些包。和起始模板一样，`fumadocs-ui` 安装 `create-fumadocs-app` 默认的 Base UI 版本：在 `package.json` 中写 `"fumadocs-ui": "npm:@fumadocs/base-ui@16.19.7"`，代码里仍然从 `fumadocs-ui/…` 导入。

</Step>
<Step>

### 添加 site.config.ts

```ts title="site.config.ts"
import { defineSiteConfig } from '@yx-elite/notestack';

export default defineSiteConfig({
  name: 'My Notes',
  description: 'My study notes.',
  repo: 'your-name/my-notes',
});
```

</Step>
<Step>

### 替换应用文件

把每个文件换成下面的版本。如果应用里有以下文件，删掉它们，主题会替代它们：`components/`、`lib/shared.ts`、`lib/layout.shared.tsx`、`app/(docs)/`、`mdx-components.tsx` 和 `source.config.ts`。下面的 `lib/source.ts` 会自己读取笔记，所以不再需要 `source.config.ts`。

<Accordions>
<Accordion title="app/global.css">

```css title="app/global.css"
@import 'tailwindcss';
@import '@yx-elite/notestack/theme.css';
```

</Accordion>
<Accordion title="app/layout.tsx">

```tsx title="app/layout.tsx"
import { Geist, JetBrains_Mono } from 'next/font/google';
import type { ReactNode } from 'react';
import { NotesRoot, notesMetadata } from '@yx-elite/notestack';
import site from '@/site.config';
import './global.css';

const sans = Geist({ subsets: ['latin'], variable: '--font-sans' });
const mono = JetBrains_Mono({ subsets: ['latin'], variable: '--font-mono' });

export const metadata = notesMetadata(site);

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <NotesRoot site={site} className={`${sans.variable} ${mono.variable}`}>
      {children}
    </NotesRoot>
  );
}
```

</Accordion>
<Accordion title="lib/source.ts">

```ts title="lib/source.ts"
import { loader } from 'fumadocs-core/source';
import { defineDocs } from 'fumadocs-mdx/macro';
import { metaSchema, pageSchema } from 'fumadocs-core/source/schema';
import { notesLanguages } from '@yx-elite/notestack';
import { notesSourcePlugins } from '@yx-elite/notestack/source';
import site from '@/site.config';

const docs = defineDocs({
  dir: 'content/docs',
  docs: {
    schema: pageSchema,
    lastModified: true,
    postprocess: { includeProcessedMarkdown: true },
  },
  meta: { schema: metaSchema },
});

export const source = loader({
  i18n: notesLanguages(site),
  baseUrl: '/docs',
  source: docs.toFumadocsSource(),
  plugins: notesSourcePlugins,
});
```

</Accordion>
<Accordion title="app/(home)/layout.tsx and page.tsx">

```tsx title="app/(home)/layout.tsx"
import type { ReactNode } from 'react';
import { NotesHomeLayout } from '@yx-elite/notestack';
import { source } from '@/lib/source';
import site from '@/site.config';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <NotesHomeLayout site={site} tree={source.getPageTree()}>
      {children}
    </NotesHomeLayout>
  );
}
```

```tsx title="app/(home)/page.tsx"
import { NotesHome } from '@yx-elite/notestack';
import { source } from '@/lib/source';
import site from '@/site.config';

export default function HomePage() {
  return <NotesHome site={site} source={source} />;
}
```

</Accordion>

import { createNotesPage } from '@yx-elite/notestack/routes';

const docs = createNotesPage({ source, site });

export default docs.Page;

</Accordion>
<Accordion title="Search, share images and llms.txt routes">

```ts title="app/api/search/route.ts"
import { searchRoute } from '@yx-elite/notestack/routes';
import { source } from '@/lib/source';

export const revalidate = false;
export const GET = searchRoute(source);
```

```tsx title="app/og/docs/[...slug]/route.tsx"
import { ogImageRoute } from '@yx-elite/notestack/routes';
import { source } from '@/lib/source';
import site from '@/site.config';

const og = ogImageRoute({ source, site });

export const revalidate = false;
export const GET = og.GET;
export const generateStaticParams = og.generateStaticParams;
```

```ts title="app/llms.txt/route.ts"
import { llmsTxtRoute } from '@yx-elite/notestack/routes';
import { source } from '@/lib/source';

export const revalidate = false;
export const GET = llmsTxtRoute(source);
```

```ts title="app/llms-full.txt/route.ts"
import { llmsFullRoute } from '@yx-elite/notestack/routes';
import { source } from '@/lib/source';

export const revalidate = false;
export const GET = llmsFullRoute(source);
```

```ts title="app/llms.mdx/[...path]/route.ts"
import { llmsPageRoute } from '@yx-elite/notestack/routes';
import { source } from '@/lib/source';

const pages = llmsPageRoute(source);

export const revalidate = false;
export const dynamicParams = false;
export const GET = pages.GET;
export const generateStaticParams = pages.generateStaticParams;
```

带普通值的 `export const` 行（`revalidate`、`dynamicParams`）必须留在每个文件里：Next.js 不运行代码就直接读取它们。

</Accordion>

## 更新

```bash
npm update @yx-elite/notestack
```

新版本带来修复、新组件和设计改进，你这边无需改动。极少数需要你修改文件的版本，会在[更新日志](https://github.com/yx-elite/notestack/blob/main/packages/notestack/CHANGELOG.md)中写明具体改法。见[更新与版本](/docs/updates)。
