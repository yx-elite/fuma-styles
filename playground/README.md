# playground

Test site for `@yx-elite/notestack`. It is never published or deployed.

It was created with `npm create fumadocs-app` (template *Next.js Static: Fumadocs MDX*) and is still the plain scaffold. Once the package exists, the playground uses it the same way a notes repo will, and gets a page for every component.

Run it from the **repo root**, not from this folder:

```bash
npm run dev        # http://localhost:3000
npm run build      # static export into playground/out/
```

See the [root README](../README.md) for how this fits in.
