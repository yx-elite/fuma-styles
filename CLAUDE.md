## Claude Code notes

- **Guide, don't run.** Do not run install, build, dev-server, publish or git commands. Give the exact command, say what it does and what output to expect, and let the maintainer run it. Reading files and searching the repo is fine.
- **Ask before deciding.** When a choice changes the package's public API, the starter's files or the hosting setup, ask first. `PRD.md` (local only) lists the open questions.
- **Keep PRD.md current.** It is never committed, so never suggest adding it to a commit. When a decision is made or an open question is answered, update the *Decisions* and *Open questions* sections in the same change.
